# Shotlist downloads

Installers for **Shotlist**, a desktop production workspace for filmmakers.

| Platform | File |
| --- | --- |
| Windows 10/11 (x64) | `Shotlist-1.1.0-win-x64.exe` |
| Linux (x64, any distro) | `Shotlist-1.1.0-x86_64.AppImage` |
| Debian / Ubuntu / Mint | `shotlist_1.1.0_amd64.deb` |
| Fedora / openSUSE | `shotlist-1.1.0.x86_64.rpm` |

Grab them from the [latest release](https://github.com/Ivoryy06/shotlist-downloads/releases/latest) or read the [install guide](https://ivy06.me/shotlist/).

This repository hosts packaged builds only. It contains no source code.
